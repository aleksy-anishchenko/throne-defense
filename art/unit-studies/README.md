# Эскизы фигурок для «Защиты трона»

Роспись с фактурой резного дерева получена во встроенном ImageGen. Векторные фигурки нарисованы отдельно с более крупными цветовыми пятнами и контрастным контуром.

- [Роспись в PNG](./units-painted.png) подходит для работы с исходной картинкой.
- [Роспись в WebP](./units-painted.webp) содержит тот же рисунок и прозрачность при меньшем размере файла.
- [Векторный лист в SVG](../../apps/web/src/render/units-vector.svg) используется в игре. Огневик и Морозко выглядят как элементали огня и льда.

Ячейка атласа занимает 192 × 192 пикселя. Роспись содержит первые две строки, векторный атлас содержит все 17 фигурок и детали их анимации. Положение стоп — около 169 пикселей от верха ячейки.

| Строка | Столбец 1         | Столбец 2           | Столбец 3      | Столбец 4        |
| ------ | ----------------- | ------------------- | -------------- | ---------------- |
| 1      | Лучник (archer)   | Баллиста (ballista) | Огневик (mage) | Морозко (frost)  |
| 2      | Бунтовщик (rebel) | Лазутчик (scout)    | Латник (armor) | Знахарь (healer) |
| 3      | Пушкарь           | Ловчий              | Колдун         | Колокол          |
| 4      | Казна             | Огр                 | Змей Горыныч   | Змеёныш          |
| 5      | Узурпатор         | Открытая Казна      | Ствол Пушкаря  | Бронзовый ствол  |
| 6      | Ловчий без сети   | Рама Звонаря        |                |                  |

При выводе через Canvas команда drawImage берёт квадрат из атласа и рисует его в нужном масштабе на поле. Демобой использует векторный лист и правила шестой волны Тронного зала.
