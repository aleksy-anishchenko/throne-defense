# Защита трона

Браузерная игра в жанре tower defense: враги идут по ковру к трону, а вы расставляете вдоль пути стражей — лучников, огневиков, Морозко и баллисты. 20 волн, после победы — бесконечный режим. Играется мышью, касанием и с клавиатуры.

Сделано на Vite + TypeScript + Vue 3. Правила игры — в отдельном пакете `packages/game` (чистый TypeScript, без Vue и DOM), интерфейс и рисование на canvas — в `apps/web`.

## Финальные волны

В v33 19-я волна состоит из четырёх огров, четырнадцати латников, трёх знахарей и двух Горынычей. На 20-й волне остаются два знахаря. Узурпатор не получает лечение от знахарей.

## Благословения

После 5, 10, 15 и 19-й волн партия останавливается и предлагает три разные награды из шести. Игрок выбирает одну:

- золото;
- запас жизней трона;
- общий бонус к урону;
- общий бонус к скорострельности;
- дополнительное золото за убийства;
- бонус к награде за отбитую волну.

Выбранные благословения складываются и действуют до конца партии. Набор наград детерминирован для состояния партии, поэтому одинаковые действия воспроизводимы в тестах.

## Специализации Баллисты

После III ступени между волнами можно купить один из двух аспектов за 180 золота:

- **Сокрушитель** — на 60% больше урона по ограм, Горынычу и Узурпатору; остальные враги и скорость стрельбы без изменений.
- **Раскол лат** — попадания снимают броню на 4 секунды, помогая всем союзникам. Повторные попадания обновляют срок, но не складываются.

Башня с аспектом отображается как IV ступень. Покупку можно отменить до начала следующей волны; после первого боя аспект закрепляется. У каждой Баллисты свой выбор.

`npm run balance:aspects` сравнивает аспекты с дополнительным Лучником III на одинаковых расстановках во всех шести залах. Это изолированные потоки врагов с характеристиками 20-й волны, без знахарей, а не доказательство полного прохождения.

## Подсказки бонусов

Ускоренные башни отмечены голубым колокольчиком. Выбор Звонаря показывает связи и проценты у его получателей; выбор ускоренной башни — её источник. В панели Звонаря указано количество получателей. При размещении пунктир и стрелка показывают только реальное усиление, без сложения с уже действующей аурой.

При размещении Лучника, Баллисты, Пушкаря, Огневика или Ловчего в зоне Звонаря заранее видны источник и будущий процент ускорения. В пересечении аур показан только сильнейший бонус.

Действует сильнейший бонус. Если сила равна, для отображения выбирается один источник; второй может подхватить ускорение после продажи первого. Морозко, Колдун, Казна и Звонари не ускоряются.

Казны с активной синергией отмечены золотой аурой и монеткой. Проценты и связи появляются только при выборе Казны — у неё и её непосредственных соседей. При размещении новой Казны будущий бонус по-прежнему показан со стрелкой и пунктиром.

## Проверки текущего и прежнего баланса

`npm run check` проверяет текущие правила, роли на шести компактных картах, начало партии, достоверность симуляций, экономику, потолок счёта, сервер и интерфейс. `npm run e2e` проверяет сборку в браузере.

Исторические критерии v8–v18 сохранены в `tools/balance/*.legacy.ts` и запускаются отдельно:

```bash
npm run test:balance:legacy
```

Это прежние рейтинги башен на классических картах, относительная эффективность поддержки и результаты фиксированных стратегий до изменения цен, дохода и боевых параметров. Их пороги не понижены; в текущем диагностическом наборе остаётся 28 падений, он не блокирует выпуск по решению владельца. Тесты механик и корректности ресурсов не перенесены в архив.

Прохождение всех 20 волн на v33 по-прежнему не подтверждено: зелёные технические проверки не доказывают полный баланс игры.

## Запуск

Нужен Node 24 (версия записана в `.nvmrc`).

```bash
npm install
npm run dev      # игра на http://localhost:5173
npm run check    # оформление, линтер, типы, тесты и сборка разом
npm run e2e      # проверка в настоящем браузере (нужен Google Chrome)
```

Все команды, устройство кода, принятые решения и план развития — в [PLAN.md](PLAN.md).
