# Защита трона

Браузерная игра в жанре tower defense. Враги идут по ковру к трону, а вы расставляете вдоль пути стражей — лучников, огневиков, Морозко и баллисты. В кампании 30 волн, после победы открывается бесконечный режим. Играется мышью, касанием и с клавиатуры.

Сделано на Vite + TypeScript + Vue 3. Правила игры — в отдельном пакете `packages/game` (чистый TypeScript, без Vue и DOM), интерфейс и рисование на canvas — в `apps/web`.

## Финальные волны

Генерал мятежников выходит на 20-й, 25-й и 28-й волнах. Его знамя даёт +3 брони бунтовщикам, латникам и лазутчикам в радиусе 1,5 клетки. Пунктир отмечает зону действия, золотой щит — бойца под защитой. Защита исчезает сразу после гибели генерала или выхода бойца из круга. Если генерал добирается до трона, тот теряет 4 жизни.

Узурпатор выходит в финале кампании на 30-й волне. Победа открывается после всей волны, а бесконечный режим начинается с 31-й.

В бесконечном режиме одновременно выходит не больше шести знахарей. Один знахарь лечит не больше трёх наиболее раненых союзников за импульс и не лечит других знахарей.

## Благословения

Выбор благословения открывается после каждой из волн 5, 10, 15, 20, 25 и 29, даже если враги прорвались к трону.

Из трёх карточек можно взять одну или обновить весь выбор за золото. Базовое распределение по редкости — 60% обычных, 25% редких и 15% легендарных. Шанс увидеть одну легендарную карту в окне — 45%, пока для этого розыгрыша есть доступные легендарные карты. Когда обычные или редкие карты исчерпаны, свободные места занимают карты другой из этих редкостей.

Первое обновление на каждом рубеже стоит 60, 80, 100, 120, 140 или 160 золота соответственно. Каждое повторное обновление в том же окне дороже предыдущего на 20 золота. После 29-й волны цены идут 160, 180, 200.

В начале партии доступно 18 благословений. В каждом наборе по три обычных, два редких и одному легендарному. Выбранная карта покидает пул до конца партии. При платном обновлении текущие три карты пропускают один показ. Они снова доступны при следующих обновлениях и на следующих рубежах.

Три разных благословения одного набора открывают дополнительный эффект. Карточка показывает прогресс после выбора и отмечена надписью «Откроет бонус», если она завершает набор.

- **Гнев стражи** добавляет 15% ко всему урону стражей.
- **Тяжёлый марш** замедляет всех врагов ещё на 10%.
- **Дар короны** один раз открывает бесплатный выбор одного благословения из четырёх обычных карт. Сначала предлагает карты, которых не было в последней тройке, затем дополняет выбор пропущенными вариантами. Если в игре осталось меньше четырёх невыбранных обычных карт, показывает их все. Выбранная карта засчитывается в свой набор.

Масло, холод Морозко и благословения вместе могут замедлить врага максимум на 80%. Сеть Ловчего полностью останавливает врага на время захвата.

## Специализации Баллисты

На III ступени можно купить один из двух аспектов при подготовке или во время волны. Базовая цена каждого — 180 золота.

- **Сокрушитель** — на 40% больше урона по ограм, Горынычу, Генералу мятежников и Узурпатору.
- **Раскол лат** — для каждой пробитой цели шанс снять броню на 4 секунды составляет 50%. Эффект снимает и защиту знамени. Повторное срабатывание начинает отсчёт 4 секунд заново.

Башня с аспектом отображается как IV ступень. Аспект, выбранный при подготовке, можно отменить до начала волны и вернуть потраченное золото. При покупке во время волны выбор закрепляется сразу. У каждой Баллисты свой выбор.

## Специализации Лучника

Лучник стоит 60 золота, улучшения — 50 и 80. На III ступени можно выбрать один аспект на тех же условиях, что у Баллисты. Базовая цена каждого — 140 золота.

- **Метка охотника** — каждый повторный выстрел по той же цели даёт +10% урона (до +100%), а смена цели сбрасывает серию.
- **Рикошет** — стрела наносит полный урон основной цели и по 60% урона ещё двум врагам поблизости.

## Специализации Огневика

Обычный поджог длится 5 секунд и наносит 18,36 урона на I ступени, 44,88 на II и 73,44 на III. На III ступени каждый Огневик может выбрать один из двух аспектов за 150 золота.

- **Кипящее масло** покрывает задетых врагов маслом и оставляет на ковре лужу на 4 секунды. Масло даёт 20% замедления и усиливает входящий урон от любого горения на 30%. Замедления от масла и холода Морозко складываются с учётом сопротивления врага. Враги уносят покрытие с собой на 2 секунды. Повторное попадание обновляет действие.
- **Дикий огонь** наносит 88,13 урона за 2 секунды синим пламенем. Это на 20% больше обычного поджога III ступени. Благословения усиливают оба вида огня.

Поджоги «Кипящего масла» и «Дикого огня» действуют на одного врага одновременно. У каждого свой срок, а масляное покрытие усиливает оба поджога на 30%, пока держится. Повторное попадание тем же аспектом обновляет его собственный поджог равной силы. У Огневика без аспекта действует обычное правило сильнейшего поджога.

## Проверка специализаций

`npm run balance:aspects` сравнивает специализации во всех четырёх игровых залах. Баллиста встречает отдельные потоки врагов с характеристиками 20-й волны. Для Огневика стенд разыгрывает каждую из волн 8–15 с её обычным составом, одинаковыми позициями стражей и одинаковым бюджетом.

Оба сравнения входят в `npm run balance`. В обычных партиях два бота также покупают специализации на заработанное золото. Один строит масло и синий огонь, второй — два синих огня.

## Подсказки бонусов

Ускоренные башни отмечены голубым колокольчиком. Выбор Звонаря показывает его получателей и вклад в ускорение. Выбор ускоренной башни показывает её источники и суммарный бонус. При размещении пунктир и стрелка отмечают будущий процент у башен, которые выиграют от постройки.

При выборе Звонаря сплошная рамка отмечает клетки в зоне сейчас, пунктир отмечает новые клетки на следующем уровне. Уже ускоренных стражей выделяет кольцо усиления. Счётчик учитывает свободные плиты и клетки со стражами, которых Звонарь может ускорить.

Ускорение получают Лучники, Баллисты, Пушкари, Огневики и Ловчие. По базовым правилам действует сильнейшая аура. «Два колокола» добавляют половину силы второго Звонаря в зоне. При равной силе первым считается тот, кого построили раньше.

Казны с бонусом соседства отмечены золотой аурой и монеткой. При выборе Казны её действующие связи и соседние Казны обведены сплошной линией. Пунктир показывает свободные плиты под соседние Казны. Ковёр, препятствия и клетки, занятые другими видами стражей, исключаются из счётчика и подсветки. При размещении новой Казны будущий бонус показан со стрелкой и пунктиром.

## Проверки текущего и прежнего баланса

`npm run check` проверяет текущие правила, роли на шести компактных картах, начало партии, достоверность симуляций, экономику, потолок счёта, сервер и интерфейс. `npm run e2e` проверяет сборку в браузере.

Исторические критерии v8–v18 сохранены в `tools/balance/*.legacy.ts` и запускаются отдельно:

```bash
npm run test:balance:legacy
```

Это прежние рейтинги башен на классических картах, относительная эффективность поддержки и результаты фиксированных стратегий до изменения цен, дохода и боевых параметров. Их пороги не понижены; в текущем диагностическом наборе остаётся 29 падений, он не блокирует выпуск по решению владельца. Тесты механик и корректности ресурсов не перенесены в архив.

В симуляции v43 все 30 волн пройдены на четырёх игровых картах. В Мраморном зале осталось 16 жизней, в остальных — по 20. Полное ручное прохождение всех залов остаётся открытой задачей.

## Запуск

Нужен Node 24 (версия записана в `.nvmrc`).

```bash
npm install
npm run dev      # игра на http://localhost:5173
npm run check    # оформление, линтер, типы, тесты и сборка разом
npm run e2e      # проверка в настоящем браузере (нужен Google Chrome)
```

Все команды, устройство кода, принятые решения и план развития — в [PLAN.md](PLAN.md).
