# Защита трона

Браузерная игра в жанре tower defense. Враги идут по ковру к трону, а вы расставляете вдоль пути стражей — лучников, огневиков, Морозко и баллисты. В кампании 30 волн, после победы открывается бесконечный режим. Играется мышью, касанием и с клавиатуры.

Сделано на Vite + TypeScript + Vue 3. Правила игры — в отдельном пакете `packages/game` (чистый TypeScript, без Vue и DOM), интерфейс и рисование на canvas — в `apps/web`.

## Финальные волны

Генерал мятежников выходит на 20-й, 25-й и 28-й волнах. Его знамя даёт +3 брони бунтовщикам, латникам и лазутчикам в радиусе 1,5 клетки. Пунктир отмечает зону действия, золотой щит — бойца под защитой. Защита исчезает сразу после гибели генерала или выхода бойца из круга. Если генерал добирается до трона, тот теряет 4 жизни.

Узурпатор выходит в финале кампании на 30-й волне. Победа открывается после всей волны, а бесконечный режим начинается с 31-й.

В бесконечном режиме одновременно выходит не больше шести знахарей. Один знахарь лечит не больше трёх наиболее раненых союзников за импульс и не лечит других знахарей.

## Благословения

Выбор благословения открывается после волн 5, 10, 15, 20, 25 и 29, если трон прошёл соответствующий отрезок без урона. Считаются отдельно волны 1–5, 6–10, 11–15, 16–20, 21–25 и 26–29. Урон лишает награды за текущий отрезок. В шапке показано, за какие волны сейчас можно её получить.

Из трёх карточек можно взять одну или обновить весь выбор за золото. Базовое распределение по редкости — 60% обычных, 25% редких и 15% легендарных. Шанс увидеть одну легендарную карту в окне — 45%, в том числе после обновления. Когда обычные или редкие карты исчерпаны, свободные места занимают карты другой из этих редкостей.

Первое обновление на каждом рубеже стоит 60, 80, 100, 120, 140 или 160 золота соответственно. Каждое повторное обновление в том же окне дороже предыдущего на 20 золота. После 29-й волны цены идут 160, 180, 200.

На каждом рубеже доступны 18 благословений. Семь обычных, шесть редких и пять легендарных.

Два благословения одного набора открывают дополнительный эффект. Повторные копии засчитываются.

- **Гнев стражи** добавляет 10% ко всему урону стражей.
- **Тяжёлый марш** замедляет всех врагов ещё на 5%.
- **Дар короны** один раз открывает бесплатный выбор одной из двух обычных карт. В первую очередь предлагает карты за пределами тройки, из которой игрок только что выбрал. Если доступных новых карт мало, дополняет пару пропущенным вариантом из этой тройки. Выбранная карта засчитывается в свой набор.

## Специализации Баллисты

После III ступени между волнами можно купить один из двух аспектов за 180 золота:

- **Сокрушитель** — на 60% больше урона по ограм, Горынычу, Генералу мятежников и Узурпатору.
- **Раскол лат** — попадания снимают броню на 4 секунды, включая защиту знамени. Повторное попадание обновляет срок.

Башня с аспектом отображается как IV ступень. Покупку можно отменить до начала следующей волны; после первого боя аспект закрепляется. У каждой Баллисты свой выбор.

`npm run balance:aspects` сравнивает аспекты с дополнительным Лучником III на одинаковых расстановках во всех шести залах. Это изолированные потоки врагов с характеристиками 20-й волны, без знахарей, а не доказательство полного прохождения.

## Специализации Лучника

Лучник стоит 60 золота; улучшения — 50 и 80. После III ступени за 120 золота выбирается один аспект:

- **Метка охотника** — последовательные выстрелы по одной цели дают по +10% урона, до +50%; смена цели сбрасывает серию.
- **Рикошет** — стрела поражает основную цель и ещё двух врагов поблизости на 60% и 30% урона.

## Подсказки бонусов

Ускоренные башни отмечены голубым колокольчиком. Выбор Звонаря показывает его получателей и вклад в ускорение. Выбор ускоренной башни показывает её источники и суммарный бонус. При размещении пунктир и стрелка отмечают будущий процент у башен, которые выиграют от постройки.

Ускорение получают Лучники, Баллисты, Пушкари, Огневики и Ловчие. По базовым правилам действует сильнейшая аура. «Два колокола» добавляют половину силы второго Звонаря в зоне. При равной силе первым считается тот, кого построили раньше.

Казны с активной синергией отмечены золотой аурой и монеткой. Проценты и связи появляются только при выборе Казны — у неё и её непосредственных соседей. При размещении новой Казны будущий бонус по-прежнему показан со стрелкой и пунктиром.

## Проверки текущего и прежнего баланса

`npm run check` проверяет текущие правила, роли на шести компактных картах, начало партии, достоверность симуляций, экономику, потолок счёта, сервер и интерфейс. `npm run e2e` проверяет сборку в браузере.

Исторические критерии v8–v18 сохранены в `tools/balance/*.legacy.ts` и запускаются отдельно:

```bash
npm run test:balance:legacy
```

Это прежние рейтинги башен на классических картах, относительная эффективность поддержки и результаты фиксированных стратегий до изменения цен, дохода и боевых параметров. Их пороги не понижены; в текущем диагностическом наборе остаётся 29 падений, он не блокирует выпуск по решению владельца. Тесты механик и корректности ресурсов не перенесены в архив.

В симуляции v43 все 30 волн пройдены на четырёх игровых картах. В Мраморном зале осталось 16 жизней, в остальных — по 20. Полное ручное прохождение всех залов остаётся открытой задачей.

## Запуск

Нужен Node 24 (версия записана в `.nvmrc`).

```bash
npm install
npm run dev      # игра на http://localhost:5173
npm run check    # оформление, линтер, типы, тесты и сборка разом
npm run e2e      # проверка в настоящем браузере (нужен Google Chrome)
```

Все команды, устройство кода, принятые решения и план развития — в [PLAN.md](PLAN.md).
