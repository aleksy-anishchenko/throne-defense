# Защита трона

Браузерная игра в жанре tower defense: враги идут по ковру к трону, а вы расставляете вдоль пути стражей — лучников, огневиков, Морозко и баллисты. 20 волн, после победы — бесконечный режим. Играется мышью, касанием и с клавиатуры.

Сделано на Vite + TypeScript + Vue 3. Правила игры — в отдельном пакете `packages/game` (чистый TypeScript, без Vue и DOM), интерфейс и рисование на canvas — в `apps/web`.

## Запуск

Нужен Node 24 (версия записана в `.nvmrc`).

```bash
npm install
npm run dev      # игра на http://localhost:5173
npm run check    # оформление, линтер, типы, тесты и сборка разом
npm run e2e      # проверка в настоящем браузере (нужен Google Chrome)
```

Все команды, устройство кода, принятые решения и план развития — в [PLAN.md](PLAN.md).
