# План проекта «Защита трона»

Рабочий документ с текущим состоянием, открытыми задачами и правилами разработки.
История изменений хранится в Git, история чисел — в `packages/game/src/data/balance.ts`.

## Текущее состояние

Актуально на 22 ноября 2026 года. Баланс v47. Работа над профилями описана в разделе
[«Защитить рейтинг»](#4-защитить-рейтинг).

- Для новых партий доступны четыре зала на сетке 7×11. Это Тронный зал, Мраморный зал,
  Светлица и Храм Анубиса. В игре девять стражей, девять типов врагов и кампания на 30 волн.
- Лучник стоит 60 золота; после III ступени он выбирает «Метку охотника» или «Рикошет»
  за 120.
- После волн 5, 10, 15, 20, 25 и 29 игрок выбирает одно из трёх благословений за отрезок без урона по трону.
  Следующий отрезок оценивается отдельно. Легендарная карточка появляется в 45% окон,
  а цена первого обновления растёт от 60 до 160 золота. Повтор в одном окне дороже на 20.
  Все 18 благословений доступны на каждом рубеже. Семь обычных, шесть редких и пять легендарных.
  «Военная казна» сразу выдаёт от 140 до 560 золота в зависимости от рубежа.
- Генерал мятежников выходит на 20-й, 25-й и 28-й волнах. Его знамя даёт +3 брони
  бунтовщикам, латникам и лазутчикам в радиусе 1,5 клетки. Узурпатор выходит на 30-й волне
  и не получает лечение. Бесконечный режим начинается с 31-й волны.
- Знахарь лечит не больше трёх наиболее раненых союзников за импульс и не лечит
  других знахарей. В бесконечном режиме одновременно выходит не больше шести знахарей.
- Для кода `2f974ad` прошёл `npm run check` с 406 тестами. Готовая сборка прошла
  `npm run e2e -w @throne/web` в настольном и мобильном режимах Chrome, включая игру
  без сервера. На игровом поле проверены все пять обликов Баллисты после постройки
  и её отдача при выстреле.
- На сборке `f4f1a7c` штатный прогон `npm run balance` по шести залам дал 0 побед из 90
  партий. Лучший результат — 11 из 20 отбитых волн. Бот всегда берёт первый предложенный
  бонус и не покупает специализации, поэтому прогон показывает результаты только текущих
  стратегий бота.
- В симуляции v43 все 30 волн пройдены на четырёх игровых картах. В Мраморном зале осталось
  16 жизней, в остальных — по 20. Светлица также пройдена в Chrome с ускоренными боями.
  Полное ручное прохождение всех залов остаётся открытой задачей.

### Оформление залов и фигурок

- Четыре зала перерисованы в виде сверху. Ковёр занимает 92% ширины клетки на прямых
  участках, повороты скруглены. Узоры, пол и помост различаются по теме зала.
- В Храме Анубиса золотой анкх из Зала фараона занял клетку нижнего обелиска.
  У входа три ступени и каменный поворот, за которым начинается синий ковёр.
  Зал фараона, Колоннада и четыре ранее выведенных зала входят в архив для старых результатов.
- Все фигурки подключены в одном SVG-атласе. У девяти стражей 31 облик. У каждого
  есть рисунок для I–III ступеней, у Лучника и Баллисты по два рисунка для
  специализаций IV ступени. Магазин показывает облики I ступени. Огневик III выглядит
  как пламя с тремя языками, Морозко — как снежинка. На поле видны отдача Пушкаря,
  бросок сети Ловчего, качание Звонаря и открытая Казна III.
  Фигурки врагов покачиваются при движении и учитывают направление пути на повороте.
- У Баллисты низкая опора и широкая дуга. У III ступени одна цельная бронзовая дуга.
  «Сокрушитель» отличается медной дугой и широким наконечником, «Раскол лат» —
  угловатой стальной дугой и узким наконечником. После постройки фигурка стоит по
  диагонали. При выстреле она отражается по горизонтали в сторону цели и даёт отдачу.
- SVG-атлас один раз рисуется на отдельном холсте при загрузке. Вращение Морозко и
  Пушкаря теперь использует готовые пиксели. Колокольчик Звонаря расположен в нижнем
  левом углу клетки, значок специализации — в нижнем правом.
- Объединение соседних стражей в отряды и стражи на несколько клеток показаны в визуальных
  прототипах. Для оценки этих идей нужна проверка читаемости заполненного поля на телефоне.

## Правила баланса

- Страж должен иметь собственную полезную роль, но без универсально лучшего выбора.
- Основные текущие проверки находятся в `packages/game/test` и
  `tools/balance/compact-roles.test.ts`.
- Любое изменение игровых чисел или поведения симуляции, влияющее на результат партии,
  требует обновления `BALANCE_VERSION`.
- Изменение баланса проверяется через `npm run towers`, `npm run balance`, `npm run check`
  и ручную партию.
- Зелёные технические тесты не заменяют подтверждённое ручное прохождение.

## Устройство проекта

- `packages/game` — правила, данные баланса и уровни; чистый TypeScript без Vue и DOM.
- `apps/web` — Vue-интерфейс, Canvas-отрисовка, звук и клиент API.
- `apps/server` — Fastify API и SQLite.
- `packages/contracts` — общие схемы и типы API.
- `tools/balance` — симуляции ботов и измерения баланса.
- `deploy` — release-скрипты, nginx, pm2 и резервное копирование.
- `.github/workflows` — проверки и автоматическая выкладка.

## Рабочие правила

- Игровая логика остаётся детерминированной и не зависит от Vue, DOM и Node.
- Схемы API меняются согласованно в `packages/contracts`, клиенте и сервере.
- Секреты не коммитятся.
- Изменения интерфейса проверяются через `npm run e2e`.
- Перед публикацией выполняется `npm run check`.
- Изменения в `main` автоматически деплоятся на сервер.

## Команды

```bash
npm run dev             # веб-приложение
npm run dev:server      # API
npm run towers          # эффективность башен
npm run balance         # симуляция стратегий по залам
npm run balance:aspects # сравнение специализаций Баллисты
npm test                # тесты
npm run e2e             # браузерная проверка
npm run check           # форматирование, линтер, типы, тесты и сборка
```
