# Правила работы с репозиторием

## Порядок выкладки

1. Создай отдельную ветку от актуальной `main`. Закоммить изменения и отправь эту ветку на GitHub.
2. Дождись, пока все проверки последнего коммита ветки в GitHub Actions пройдут успешно. Если проверка упала, исправь причину в той же ветке и дождись повторной проверки.
3. Только после зелёных проверок слей ветку в `main` на GitHub. Дождись успешного завершения процесса «Деплой» для коммита в `main`.
4. Открой главное меню игры. В строке «Версия» перед датой сборки должен стоять короткий идентификатор (хеш) выложенного коммита из `main`. [Сайт игры](https://throne-defense.ru/)
